# Biorona Signature UI — Design Principles

## 1. Khas Biorona, bukan tiruan UI iOS
Liquid Glass dipakai sebagai bahasa material pada navigasi dan kontrol. Konten bunga tetap bersih, tajam, dan mudah dibaca.

## 2. Fungsi pelanggan di atas dekorasi
Prioritas klik:
1. Lihat katalog
2. Cari/filter produk
3. Lihat harga & detail
4. Pesan via WhatsApp
5. Custom Bouquet

## 3. Mobile-first
- Tombol utama minimum 44px.
- Sticky order bar di mobile.
- Katalog dua kolom di HP untuk scanning cepat.
- Tidak ada login, cart, atau checkout.

## 4. SEO-first
- H1 tunggal yang jelas.
- Halaman produk individual.
- Metadata + canonical + OpenGraph.
- sitemap.xml + robots.txt.
- JSON-LD Florist, ItemList, dan Product.
- Copy memuat intent lokal secara natural tanpa keyword stuffing.

## 5. Performance
- Tidak ada library animasi tambahan.
- Animasi CSS ringan.
- Static export didukung.
- Gambar local dan Next Image unoptimized untuk portability ke cPanel.
